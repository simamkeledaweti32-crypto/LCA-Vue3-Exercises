## Project Description
Property Mini-Listings app for Homes & Beyond real estate. Displays Cape Town short-term rental properties in card layout with search, sort, and availability indicators.

## Features
- Dynamic property listings from data array
- Search by title or location
- Sort by price: Low to High / High to Low
- Property details: title, price, location, type, image
- "Not Available" ribbon for unavailable properties
- Header with brand name + total property count
- Responsive grid layout

## How to Run
1. Clone repository
2. Run `npm install`
3. Run `npm run dev`
4. Open localhost URL
