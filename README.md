## Project Description
Shopping cart for Cooking Masterclass. Users browse courses, add to cart, adjust quantities, and see total price. No backend - all cart logic in browser.

## Features
- Course catalog with image, name, price
- Add to cart functionality  
- Adjust quantity with + and - buttons
- Remove items from cart
- Live total calculation
- Cart item count badge
- Responsive layout

## How to Run
1. Clone repository
2. Run `npm install`
3. Run `npm run dev`
4. Open localhost URL
