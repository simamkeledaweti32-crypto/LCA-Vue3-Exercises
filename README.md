## Project Description
Fitness class scheduler for FlexCore Fitness. Staff can add, view, and delete workout sessions with form validation. Data stored locally in browser.

## Features
- Add new class sessions: name, instructor, time, duration, capacity
- Delete sessions with "Cancel" button
- Form validation for empty fields
- Live count: total sessions + total capacity
- "No sessions scheduled" message when list is empty
- Responsive design for mobile/desktop

## How to Run
1. Clone repository
2. Run `npm install`
3. Run `npm run dev`
4. Open localhost URL
